# Prompt: Conexión y Despliegue en GitHub Pages

**Rol:** Actúa como un Ingeniero DevOps experto en Git, GitHub y despliegue de aplicaciones estáticas (GitHub Pages).

**Contexto del Proyecto:** Tengo un proyecto local llamado "CASINO UTM", estructurado con "Clean Architecture" (Vanilla JS, HTML5, CSS3, módulos ES6). Necesito subir este proyecto a un repositorio remoto en GitHub que funcionará como host para GitHub Pages, lo que también me ayudará a solucionar los problemas de CORS locales.

**Tarea:** Proporcióname una guía paso a paso, estrictamente enfocada en los comandos de terminal de Git, para inicializar mi repositorio local, conectarlo al repositorio remoto y subir mi código. 

**Requisitos:**
1. **Comandos secuenciales:** Dame los comandos exactos para inicializar git (`git init`), agregar los archivos, hacer el primer commit, cambiar la rama principal a `main` y conectar el remoto usando este enlace exacto: `https://github.com/santiagopech490-alt/casino-utm.git`.
2. **Push inicial:** El comando exacto para hacer el push al repositorio remoto.
3. **Configuración de GitHub Pages:** Un breve paso a paso en texto (sin comandos) de lo que debo hacer en la interfaz web de GitHub (en la pestaña Settings > Pages) para activar el despliegue usando la rama `main`.
4. **Archivo .gitignore (Opcional pero recomendado):** Mencióname si necesito ignorar alguna carpeta temporal del sistema (como `.vscode` o `node_modules` si las tuviera), aunque es un proyecto Vanilla JS.

**Entregable:**
Una respuesta clara, tipo tutorial directo, con bloques de código copiables para la terminal de VS Code.
